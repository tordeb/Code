# First vs Second Order Markov Chains

Code and analysis for the dissertation: "A Comparative Study of First- and Second-Order Markov Chains to Predict Transition Sequences in a Healthcare Context."

The dataset matches [MockVsActualHospitalCare](https://github.com/MarcoFelipeKing/MockVsActualHospitalCare) and comprises 62 observed care episodes collected at an NHS respiratory ward, recording sequential hand-to-surface contacts of healthcare workers (HCWs) during patient care.

## Overview

Both first- and second-order Markov chains are developed and evaluated across three simulation methods:

- Fixed-length: sequences run for the mean observed episode length,
- Fitted-length: sequence lengths sampled from a fitted negative binomial (or Poisson) distribution,
- Terminating-state: sequences end naturally upon reaching the *Out* state.

Model performance is evaluated using:

- Transition matrix accuracy: Mean Absolute Error (MAE) against observed and held-out test matrices,
- Distributional similarity: Hellinger distance for episode lengths and category visit distributions,
- Sequence similarity: Levenshtein distance, Needleman-Wunsch global alignment, and Smith-Waterman local alignment,
- Robustness and Sensitivity: bootstrap resampling and matrix perturbation across five noise levels.

## Structure

- `first_order/` — first-order model implementation
- `second_order/` — second-order model implementation
- Each contains: `config.py`, `data_loader.py`, `transition_matrices.py`, `simulations.py`, `metrics.py`, `plotting.py`, `main.py`.

## Key Findings

The first-order terminating-state model is recommended for datasets of this size. The second-order model produced modest improvements in sequence similarity but was limited by matrix sparsity and poor generalisation given the available data.

## Ways This Research Can Be Extended

1. Evaluate the second-order model with a larger dataset to determine whether its performance improves sufficiently to justify the additional complexity.
2. Compare Markov chain simulated sequences with those generated by large language models (LLMs) using sequence alignment metrics.
3. Extend the research to different ward types, care procedures, or patient room configurations.
4. Incorporate surface and air contamination levels into the transition model to predict pathogen exposure.
5. Analyse hand hygiene patterns from the transition sequences to identify high-risk contact behaviours.
